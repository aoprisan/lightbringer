=== 9d. Per-city sprite set — VESPER ROW (monastic, watched) ===

Re-skins the city's BUILT WORLD so Vesper Row reads as a cloistered, faith-heavy
quarter: austere stone cells, barred windows, studded doors, ecclesiastical and
oppressive. Same silhouettes as the base sprites — only the material changes — so
each still reads as its kind. Here a lit window is a forbidden candle in a watched
cell.

OUTPUT FOLDER: art/vesper/    (the loader tries this city folder, then falls back
to the base art/<name>.png). Files to produce, same names as the base set:
  ground.png  dwelling-dark.png  dwelling-lit.png  dwelling-awakened.png
  dwelling-snuffed.png  conduit.png  press.png  shrine.png  font.png  obelisk.png

SHARED, DO NOT re-skin (universal forces): keeper-node, keeper-patrol,
player-lantern, veil-scar, flame-spark, obelisk-spent (the cracked face is
universal — only the STANDING obelisk.png is re-skinned below). Vesper Row reuses the base ones (the
Order is the same everywhere — most at home here).

RULES (read once):
- No transparency. Generate every sprite isolated on a flat solid #0B0E1A.
  Never a white background — flame glow would halo.
- 1024×1024, square, single centered subject, no text, no watermark, no border.
- DWELLING CONTINUITY: generate dwelling-dark FIRST, then use Gemini's IMAGE-EDIT
  mode on that image for lit / awakened / snuffed, so all four share one
  silhouette.
- ground.png must tile SEAMLESSLY, edge to edge, no focal point.

Each block below is self-contained — copy any one whole.
