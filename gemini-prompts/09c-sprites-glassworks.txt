=== 9c. Per-city sprite set — THE GLASSWORKS (brittle, bright) ===

Re-skins the city's BUILT WORLD so the Glassworks reads as a glassmakers' quarter:
brick kilns, leaded glass panes, blown-glass lanterns, faceted reflections,
crushed cullet underfoot. Same silhouettes as the base sprites — only the material
changes — so each still reads as its kind.

OUTPUT FOLDER: art/glassworks/    (the loader tries this city folder, then falls
back to the base art/<name>.png). Files to produce, same names as the base set:
  ground.png  dwelling-dark.png  dwelling-lit.png  dwelling-awakened.png
  dwelling-snuffed.png  conduit.png  press.png  shrine.png  font.png  obelisk.png

SHARED, DO NOT re-skin (universal forces): keeper-node, keeper-patrol,
player-lantern, veil-scar, flame-spark, obelisk-spent (the cracked face is
universal — only the STANDING obelisk.png is re-skinned below). The Glassworks
reuses the base ones.

RULES (read once):
- No transparency. Generate every sprite isolated on a flat solid #0B0E1A.
  Never a white background — flame glow would halo.
- 1024×1024, square, single centered subject, no text, no watermark, no border.
- DWELLING CONTINUITY: generate dwelling-dark FIRST, then use Gemini's IMAGE-EDIT
  mode on that image for lit / awakened / snuffed, so all four share one
  silhouette and the same arrangement of glass panes.
- ground.png must tile SEAMLESSLY, edge to edge, no focal point. Keep the glints
  subtle so it still reads as background, not a focal sparkle.

Each block below is self-contained — copy any one whole.
