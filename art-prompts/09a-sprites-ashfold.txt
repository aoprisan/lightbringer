=== 9a. Per-city sprite set — ASHFOLD (charred tinder) ===

Re-skins the city's BUILT WORLD so Ashfold reads as a fire-scarred quarter:
charred timber, scorched thatch, soot, ember-glow in the cracks. Same silhouettes
as the base sprites — only the material changes — so each still reads as its kind.

OUTPUT FOLDER: art/ashfold/    (the loader tries this city folder, then falls back
to the base art/<name>.png). Files to produce, same names as the base set:
  ground.png  dwelling-dark.png  dwelling-lit.png  dwelling-awakened.png
  dwelling-snuffed.png  conduit.png  press.png  shrine.png

SHARED, DO NOT re-skin (universal forces): keeper-node, keeper-patrol,
player-lantern, veil-scar, flame-spark. Ashfold reuses the base versions.

RULES (read once):
- No transparency. Generate every sprite isolated on a flat solid #0B0E1A.
  Never a white background — flame glow would halo.
- 1024×1024, square, single centered subject, no text, no watermark, no border.
- DWELLING CONTINUITY: generate dwelling-dark FIRST, then use Gemini's IMAGE-EDIT
  mode on that image for lit / awakened / snuffed, so all four share one
  silhouette. The game swaps states on the same node — continuity beats per-image
  beauty.
- ground.png must tile SEAMLESSLY, edge to edge, no focal point.

Each block below is self-contained — copy any one whole.

--- ashfold/dwelling-awakened.png (IMAGE-EDIT of dwelling-dark) ---
Edit this image: the same charred row-house transfigured. Serene and sacred — a soul awake in the ruin, NOT a fresh fire. Same silhouette and position. Flat solid #0B0E1A background, no text, 1024×1024.

No warm colour anywhere. It must look permanently silenced atop its own ash, worse than merely burnt. Same silhouette and position. Flat solid #0B0E1A background, no text, 1024×1024.
