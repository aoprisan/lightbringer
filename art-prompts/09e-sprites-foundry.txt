=== 9e. Per-city sprite set — THE EMBER FOUNDRY (industrial, molten) ===

Re-skins the city's BUILT WORLD so The Ember Foundry reads as a deep industrial
casting-quarter: brick kiln-houses, iron and firebrick, runnels of molten light.
Same silhouettes as the base sprites — only the material changes — so each still
reads as its kind. This city's SIGNATURE structure is the lightwell (font), so its
re-skin is included here; it does not use ward-obelisks.

OUTPUT FOLDER: art/foundry/    (the loader tries this city folder, then falls back
to the base art/<name>.png). Files to produce, same names as the base set:
  ground.png  dwelling-dark.png  dwelling-lit.png  dwelling-awakened.png
  dwelling-snuffed.png  conduit.png  press.png  shrine.png  font.png

SHARED, DO NOT re-skin (universal forces): keeper-node, keeper-patrol,
player-lantern, veil-scar, flame-spark, obelisk(-spent). The Foundry reuses the
base ones.

RULES (read once):
- No transparency. Generate every sprite isolated on a flat solid #0B0E1A.
  Never a white background — flame glow would halo.
- 1024×1024, square, single centered subject, no text, no watermark, no border.
- DWELLING CONTINUITY: generate dwelling-dark FIRST, then use image-edit mode on
  that image for lit / awakened / snuffed, so all four share one silhouette.
- ground.png must tile SEAMLESSLY, edge to edge, no focal point.

Each block below is self-contained — copy any one whole.

--- foundry/ground.png ---
Style: hand-painted dark-fantasy game asset, medieval city at night, ink-and-gilt feel. Palette: deep indigo #0B0E1A, soot-charcoal, firebrick red-brown; warm ember-gold #F5C66B for any light. Soft painterly edges, no outlines. View: top-down. Single subject, flat solid #0B0E1A background, 1024×1024, no text, no border.
Seamless tileable texture of a foundry casting-floor seen from straight above at night: scorched firebrick and iron grating laid in a grid, fine drifts of grey ash, a few cooled runnel-channels cut in the surface catching the faintest ember glow. Low contrast, industrial, swept and worked, no focal point, edges must tile seamlessly. 1024×1024.

View: three-quarter top-down ~60°, light from its own flame only. Single centered subject, flat solid #0B0E1A background, 1024×1024, no text, no border.
A small brick kiln-house, squat with a heavy firebrick chimney and a banded-iron door, a cold dead forge-mouth and an empty iron lamp-bracket. Completely unlit and cold. Soot-dark, almost a silhouette, a thin line of moonlight on the brick.

The brick stays dark; only the fire is warm. Keep the exact same silhouette and position. Flat solid #0B0E1A background, no text, 1024×1024.

--- foundry/font.png (the city's signature lightwell) ---
