--- WHAT THIS IS ---
The knights are the village watch — the foes. They have two states, each its own
sprite today: knight-guard.png (lurking watch) and knight-engage.png (charging,
spear levelled). Both slide when they move. These four frames are the stride
extremes of a 3-frame walk cycle PER STATE the game plays while a knight moves:
  stepA  →  base state sprite  →  stepB  →  base  →  …
and the base state sprite alone when standing. Guard = a slow wary PATROL step;
engage = a fast RUNNING charge stride. The captain and priest reuse these frames
via the game's fallback.

--- GENERATION RULES (read once) ---
- Use Gemini's IMAGE-EDIT mode on the matching base sprite — the two guard frames
  from art/knight-guard.png, the two engage frames from art/knight-engage.png. Do
  NOT generate from scratch — continuity beats per-frame beauty, and a knight must
  stay recognisably the SAME knight across all four frames.
- Keep EVERYTHING fixed except the gait: same armour, same tabard, same shield and
  spear, same colours, same lighting, same SIZE/SCALE, same CENTER. Only legs,
  body lean, and the weapon's counter-swing change. Misregistered frames jitter on
  swap.
- No transparency. Flat solid #060B08 (graveyard green-black) background, exactly
  like the base sprites. Never white.
- Face SCREEN-RIGHT (or keep the base sprite's facing). The game mirrors the
  sprite to face left; do not bake in a left-facing pose.
- Three-quarter top-down (~60°), the same camera as the base sprites.
- Readable small: the stride is a SILHOUETTE change (leg spread, body lean, weapon
  swing), not fine armour detail.
