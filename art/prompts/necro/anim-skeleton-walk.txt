--- WHAT THIS IS ---
The skeleton is the raised minion — the horde is many and drawn SMALL. Today it
draws as ONE static sprite (art/skeleton.png) and slides when it advances. These
two frames are the stride extremes of a 3-frame shamble cycle the game plays while
a minion moves:
  stepA  →  skeleton.png (neutral)  →  stepB  →  skeleton.png  →  …
and the neutral base sprite alone when it has stopped. The three skeleton VARIANTS
(brute / wight / revenant) and the priest reuse these same base frames via the
game's fallback, so getting this one shamble right animates the whole horde.

--- GENERATION RULES (read once) ---
- Use Gemini's IMAGE-EDIT mode on art/skeleton.png for BOTH frames. Do NOT
  generate from scratch — continuity beats per-frame beauty.
- Keep EVERYTHING fixed except the gait: same skull, same ribcage, same rusted
  blade, same green eye-fire, same colours, same lighting, same SIZE/SCALE, and
  the same CENTER (the body stays centered in the 1024 square). Only the legs and
  the swinging arm/blade move, plus a tiny body bob. Misregistered frames jitter
  on swap.
- No transparency. Flat solid #060B08 (graveyard green-black) background, exactly
  like the base sprite. Never white — the green glow would halo.
- Face SCREEN-RIGHT (or stay front-facing 3/4 as the base does). The game mirrors
  the sprite to face left; do not bake in a left-facing pose.
- Three-quarter top-down (~60°), the same camera as the base sprite.
- This is a TINY sprite: the shamble must read as a clear SILHOUETTE change — leg
  spread and blade swing — not fine bone detail. Keep it frail and lurching, never
  a smooth confident march.
